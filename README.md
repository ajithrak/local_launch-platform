# LocalLaunch

A reusable website platform for local businesses (gyms, restaurants, and more) — sites are generated from typed configuration, not by copy-pasting templates.

## Structure

```
apps/            Next.js applications (one per industry)
packages/
  tsconfig/       Shared TypeScript base configs
  eslint-config/  Shared ESLint flat configs
```

## Getting started

```bash
pnpm install
pnpm dev
```
